# Ayuen's Portfolio

A responsive portfolio website introducing Ayuen, a software engineering student. It includes a home page, biography and skills, a personal photo and video gallery, and contact details.

## Pages

- **Home** (`index.html`) — introduction and areas of focus.
- **About Me** (`about.html`) — biography, education, skills, and interests.
- **Gallery** (`gallery.html`) — personal photo and video.
- **Contact** (`contact.html`) — email contact link.

## Run locally

Open `index.html` in a browser, or serve the project directory with a local web server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`. Bootstrap is loaded from its CDN, so an internet connection is needed for Bootstrap's layout and navigation components.

## Project files

- `mainstyles.css` — shared styles and responsive layout.
- `WhatsApp Image 2026-10-19 at 8.38.30 AM.jpeg` — profile photo used on the About and Gallery pages.
